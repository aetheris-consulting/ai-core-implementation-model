# Agent Harness Architecture (AHA)

AHA is the Universal Grammar of Agency.

States:
- Architecture at Rest
- Organization with Context
- Agent in Interaction

Authority flows downward.
Telemetry flows upward.
Children may add constraints.
Children may not remove parent constraints.

AHA contains:
- Actors
- Roles
- Authority
- Boundaries
- Observers
- Child Harnesses
