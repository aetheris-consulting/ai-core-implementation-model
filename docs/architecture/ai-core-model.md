# AI Core Implementation Model

The AI Core Implementation Model is the umbrella architecture.

Planes:
- Knowledge Plane (WFKB/WFKC)
- Control Plane (DOC)
- Exchange Plane (THOS)
- Agency Plane (AHA)
- Workflow Plane (WEOF)
- Simulation Plane (AHA-SIM)
- Commitment Plane (Gate 8)
- Memory Plane (UMSS)

Core Doctrine:
Knowledge informs.
Control constrains.
Agency acts.
Workflow routes.
Simulation tests.
Commitment authorizes.
Memory remembers.
